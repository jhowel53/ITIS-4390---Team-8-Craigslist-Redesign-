# ITIS-4390 Team 8 Craigslist Redesign

## Requirements
- Visual Studio Code
- Live Server extension for VS Code
- A web browser such as Chrome

## Run the project locally
1. Download or clone the project repository.
2. Open Visual Studio Code.
3. Select **File > Open Folder** and choose the project folder.
4. Open `Pages/index.html`.
5. Right-click `index.html` and select **Open with Live Server**.
6. The Craigslist redesign will open in your default browser.

## Notes
- Keep the project folder structure the same so the shared components, scripts, styles, and icons load correctly.
- Navigation between prototype pages includes a visible loading spinner so users receive feedback while new content is opening.
